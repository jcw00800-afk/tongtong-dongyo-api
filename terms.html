1. 목적

TongTong Dongyo API(이하 "이 앱")는 개인 제작자가 본인이 운영하는 유튜브 채널에 직접 만든 동요 영상을 업로드하기 위해 사용하는 개인용 자동화 도구입니다. 이 앱은 일반에 공개되거나 판매되지 않습니다.

2. 이용 범위

이 앱은 앱 소유자 한 사람이 본인 소유 채널에만 사용합니다. 제3자에게 계정 접근 권한을 제공하지 않습니다.

3. YouTube 서비스 약관

이 앱은 YouTube 서비스 약관과 Google API 서비스 약관을 준수하며, YouTube Data API를 통한 업로드와 재생목록 관리는 본인 채널 범위 안에서만 이루어집니다.

4. 보증의 부인

이 앱은 개인 용도로 "있는 그대로" 제공되며, 별도의 상업적 보증을 제공하지 않습니다. API 할당량·정책 변경 등 외부 요인으로 동작이 제한될 수 있습니다.
