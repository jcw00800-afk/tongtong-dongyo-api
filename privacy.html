개인정보처리방침

시행일: 2026년 11월 27일 · 최종 수정일: 2026년 11월 27일

TongTong Dongyo API(이하 "이 앱")는 개인이 본인의 유튜브 채널에 영상을 올리기 위해 만든 개인용 도구입니다. 이 앱은 일반 이용자로부터 개인정보를 수집하지 않으며, 아래와 같이 Google 사용자 데이터를 사용합니다.

1. 접근하는 Google 사용자 데이터

항목목적
YouTube 채널 기본 정보(채널 ID·이름)업로드 대상 채널이 본인 소유 채널과 일치하는지 확인
YouTube 영상 업로드 권한(youtube.upload)본인이 제작한 동요 영상을 본인 채널에 업로드
재생목록 조회·추가 권한(youtube)업로드한 영상을 주제별 재생목록에 연결

2. 사용 목적과 범위

  • 영상 업로드, 아동용(Made for Kids) 설정, 예약 공개, 재생목록 연결 — 앱 소유자 본인의 4개 채널에 한정됩니다.
  • 다른 사람의 계정·영상·시청 기록에는 접근하지 않습니다.
  • 광고, 프로파일링, 통계 분석 목적으로 사용하지 않습니다.

3. 저장과 보관

  • OAuth 승인 정보(리프레시 토큰)는 앱 소유자의 개인 컴퓨터에만 파일로 저장되며 외부 서버로 전송되지 않습니다.
  • 업로드에 사용한 영상·메타데이터는 소유자의 PC와 본인 유튜브 채널에만 존재합니다.
  • 승인은 언제든지 Google 계정의 타사 앱 액세스에서 철회할 수 있으며, 철회 시 저장된 토큰은 더 이상 사용할 수 없습니다.

4. 제3자 제공

이 앱은 어떤 Google 사용자 데이터도 제3자에게 판매·이전·공유하지 않습니다. 다만 영상 게시를 위해 YouTube Data API로 Google에 전송되는 것은 당연히 포함됩니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 앱의 Google 사용자 데이터 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

6. 아동의 개인정보

이 앱은 시청자로부터 어떠한 정보도 수집하지 않습니다. 업로드되는 콘텐츠는 아동용 동요 영상이며, 영상 자체에는 아동의 개인정보가 포함되지 않습니다.

English summary

This app is a private tool that lets its owner upload his own children's-song videos to the four YouTube channels he owns. It accesses only the YouTube Data API scopes youtube.upload and youtube, and only to upload videos, set made-for-kids and scheduled publishing options, and add them to playlists on the owner's own channels. OAuth tokens are stored only on the owner's personal computer. No user data is collected from anyone else, and nothing is sold, transferred, or shared with third parties. Use of Google user data adheres to the Google API Services User Data Policy, including its Limited Use requirements. To revoke access, visit https://myaccount.google.com/permissions.
