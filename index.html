TongTong Dongyo API (앱 이름: ssullok)

통통동요 자동 업로드 도구 · Personal automation tool for the owner's YouTube channels

이 앱은 무엇인가요?

TongTong Dongyo API는 만든 사람 본인이 운영하는 4개 유튜브 채널(한국어 · 영어 · 일본어 · 중국어 유아 동요 채널)에 직접 제작한 동요 영상 4편을 한 번에 올리기 위해 만든 개인용 자동화 도구입니다. 일반 사용자에게 공개되거나 판매되는 서비스가 아니며, 다른 사람의 계정이나 데이터에는 접근하지 않습니다.

이 앱(Google Cloud 프로젝트 ssullok-shorts, 앱 이름 ssullok)은 같은 소유자의 다른 유튜브 채널 썰록홈즈의 업로드 자동화에도 함께 사용됩니다. 두 경우 모두 소유자 본인 채널에 본인 영상을 올리는 용도로만 쓰입니다.

동작 방식

  • 제작한 영상 파일과 제목 · 설명 · 태그 · 재생목록 정보를 준비합니다.
  • YouTube Data API v3로 본인 소유 채널에만 영상을 업로드하고, 아동용 설정과 예약 공개, 재생목록 연결을 함께 처리합니다.
  • 업로드 작업은 본인의 PC에서 실행되며, 승인 정보(OAuth 토큰)는 본인 PC에만 저장됩니다.

English

TongTong Dongyo API is a private automation tool built by an individual creator to upload his own children's-song videos to the four YouTube channels he owns (Korean, English, Japanese and Chinese). It is not a public service. It requests YouTube Data API v3 access only to upload videos, set made-for-kids and scheduled publishing options, and add videos to playlists on the owner's own channels. OAuth tokens are stored only on the owner's computer; no data is collected from or shared with anyone else.
